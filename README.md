# Traveling Project

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скачайте ngrok с официального сайта (https://ngrok.com/download) и поместите ngrok.exe в корневую директорию проекта.

3. Запустите Django сервер:
```bash
python manage.py runserver
```

4. В отдельном терминале запустите ngrok:
```bash
python run_ngrok.py
```

5. Скопируйте публичный URL, который будет выведен в консоли после запуска ngrok.

6. Обновите настройки в файле `settings.py`:
   - Убедитесь, что `ALLOWED_HOSTS` содержит необходимые домены
   - При необходимости обновите `CSRF_TRUSTED_ORIGINS` с вашим ngrok URL

## Примечания

- Ngrok URL меняется при каждом перезапуске ngrok (в бесплатной версии)
- Для продакшена рекомендуется использовать платную версию ngrok с фиксированным доменом
- Убедитесь, что порт 8000 свободен перед запуском
